# CineSynapse Studio

A website built for the **CineSynapse Studio** YouTube channel to give it a professional web presence and showcase its content beyond YouTube itself.

## About

CineSynapse Studio is a YouTube channel. This site was designed and built from scratch to strengthen the channel's brand identity and give viewers a place to explore its content outside of YouTube.

## Tech Stack

- **HTML5** – page structure and content
- **CSS3** – styling and responsive layout
- **JavaScript** – interactivity

## Features

- Clean, responsive layout that adapts across devices
- Simple, intuitive navigation for visitors
- Custom design built without a framework or template

## Getting Started

To run this project locally:

```bash
git clone https://github.com/TinaCode-b/CineSynapseStudio.git
cd CineSynapseStudio
```

Then open `index.html` in your browser.
